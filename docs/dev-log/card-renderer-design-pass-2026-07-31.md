# 卡片渲染器设计整改(「现在设计很粗糙」+「标题超级粗」)

**日期**:2026-07-31
**触发**:Yuqi 两条批评 —— 设计粗糙(死白多、无视觉锚)、文字阶级不好(标题 900 超粗)。

## 改了什么(card.css / card.js)

1. **字重全线回归铁律**(400 默认 / 500 关键数据 / 600 顶格,紧迫感=字号不=加粗):
   - 封面 hook `.ddhq__cvhook` 900 → **600**
   - 数据卡标题 `.ddhq__h` 900 → **600**;英文标题 700 → **600**(两处)
   - 新日期 `.ddhq__newtx` 700 → **600**
2. **封面州形水印** `.ddhq__cvmark`:cover payload 带 `map.state` 时,右下超淡(3.8%)
   州剪影作视觉锚,填下半空区。digest 等无州封面自动跳过。
3. **ledger 细线**(设计 canon:空区读作「留白」不是「没做完」):
   - 封面 `.ddhq__cvledger`:sub 之下到页脚,自上而下渐隐的横向账本线
   - 数据卡 `.ddhq__base:empty`(li 页无 tip 无印章时)同样铺线
4. **荧光高亮条**边缘曲线收顺(旧 path 波动过大,放大后毛糙)。
5. **展示行禁标点**:巨字里不再出现「,」「:」(payload 侧改行文;待入 validate 规则)。
