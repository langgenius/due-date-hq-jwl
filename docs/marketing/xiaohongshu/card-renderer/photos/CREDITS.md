# 封面实景照片 · 来源与许可

**取图纪律(与核事实同一标准):** 图必须是**那个州、那场灾害**的真实记录,核不到地点就不用。
优先级:① FEMA / NOAA / USGS 等联邦政府作品(公有领域)② 维基共享资源上 CC0 的照片
③ Unsplash / Pexels(商用免署名)。**CC BY 需署名的作为备选**,社媒卡上挂 credit 很别扭。

其余筛选标准:不拍可辨认的人与受灾者窘境;构图中间要留空(白卡垂直居中压在上面);
画面要平、要闷 —— 它是背景,高对比强色彩会跟白卡打架。

**规则变更类怎么配图**:灾害类要求「那场灾害的实拍」;规则变更没有「现场」,配的是
**被征税/被规范的对象本身**(如尼古丁袋)。这不是冒充事件,不违反核实纪律。
优先选公有领域或 CC0;**CC BY-SA 一律不用**(ShareAlike 有传染性,会波及品牌素材),
也避开带明显品牌标识的产品照 —— 卡上出现某个牌子等于点名一家。

**仍无图的 6 条**(AZ / MT×2 / MI / MS / WI):暂无该事件的公开影像,继续走方块地图封面。
不为了配图硬凑 —— 找到再补,补上后重跑生成器即可自动切换到实景封面。
