## 一天发三条会不会太多

不会,但**顺序有讲究**:三条面向的客户群不重叠 —— 夏威夷是受灾地区的所有申报人,纽约是尼古丁零售
与分销,阿拉巴马是烟草批发与县级申报。同一个人不太可能三条都相关,所以不是刷屏,是覆盖。

若只想发两条,砍掉阿拉巴马 —— 它的第一个动作日在 9月1日,还有时间;夏威夷两周内到期,纽约的
盘存日也压着,这两条不能等。
