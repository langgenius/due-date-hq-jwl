**小红书配文**

```
纽约州 9月1日 起把烟草税扩到「替代性尼古丁产品」(尼古丁袋这类)。但真正会踩的坑不是开征日 —— 是库存税。
```

## 3 · IRS:某些 CRAT 安排列为 listed transaction(IR-2026-82)

**小红书标题**:`手上有CRAT客户的,先翻这份文件`
(备选:`IRS盯上这类慈善信托|参与方要报8886` / `被列名了:CRAT+年金那套操作`)

**小红书配文**

```
财政部与 IRS 发布终局条例(T.D. 10051),把某些「慈善剩余年金信托(CRAT)」安排列为 listed transaction。7月9日 生效。

【被盯上的是哪种操作】
用增值资产设立名义上的 CRAT → 在信托内把资产卖掉 → 用价款买年金 → 再按「信托分配规则不适用」的口径申报年金付款。

【谁要报哪张表】
· 参与的纳税人(个人 / 信托)—— 随申报表报送 Form 8886
· 材料推介方(material advisor)—— 报送 Form 8918
· 仅作为慈善剩余受益人、别无其他角色或权益的组织 —— 不视为参与方,也不适用 §4965 消费税与相应披露

未按规定披露有专门罚则。手上有 CRAT 客户的,先把设立与资产处置记录翻一遍,判断是否落入「实质相似」范围。

来源:IRS IR-2026-82 · T.D. 10051

#美国报税 #CPA #注册会计师 #IRS #信托 #税务合规 #EA #华人会计师
```

**LinkedIn 配文**(文档帖,上传 `irs-li-carousel.pdf`)

```
Certain charitable remainder annuity trust arrangements are now listed transactions — Treasury and IRS final regulations, effective July 9, 2026.
T.D. 10051 (announced as IR-2026-82) identifies a specific CRAT pattern, and substantially similar transactions, as listed transactions: fund a purported CRAT with appreciated property, sell that property inside the trust, buy an annuity with the proceeds, then report the annuity payments as if the trust distribution rules did not apply. Once a transaction is listed, participating taxpayers disclose on Form 8886 with their return and material advisors disclose on Form 8918, with separate penalties for failure to disclose. There is a carve-out: an organisation whose only role or interest is as the charitable remainderman is not treated as a participant, and stays outside the section 4965 excise tax and its disclosure requirements.
If you have CRAT clients, this is a file-review task, not a filing-season task. IRS source in the comments.
```
