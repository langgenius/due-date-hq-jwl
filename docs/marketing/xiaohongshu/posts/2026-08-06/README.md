**小红书配文**

```
华盛顿的联邦报税延期昨天(8月5日)到期了。同一周,华盛顿新增了 8 项火灾相关声明 —— 但那不等于新的延期。

【已经结束的】

【8月3日 新来的】

【现在的状态】

WA-2025-03 当初就是从一份紧急状态声明(EM)出来的,不是重大灾害声明。所以 EM-3650 有可能带来新的 IRS 减免 —— 但在公告出来之前,别按「已经延了」安排客户。
```
