## 这批 FEMA 新声明为什么今天不发

2026-07-20 → 08-06 窗口里 FEMA 出了 22 项声明,其中 6 项(5 DR + 1 EM)理论上能引出 IRS 减免。
但**对 CPA 没有可执行动作** —— FEMA 宣布灾害不改任何截止日,IRS 至今零公告(最近一批仍是 7月13日,
已 24 天)。现在发,读者读完只能干等,这不是 alert,是噪音。

**该等的时点**:IRS 一旦发布就改发实际公告;若到 8月14–20 仍无动静,再发「等待窗口」那条。
发那条时**必须写明**「约 13 天的批次滞后」是我们的观察、不是 IRS 的承诺 —— IRS 从不预告发布时间。

**最值得优先盯的一项**:西弗吉尼亚 DR-4932(Lewis、Upshur 两县)是这批里**唯一宣布了个人援助(IA)**
的,历史上 IA 与 IRS 减免的相关性最高。

**两处发前务必区分的混淆:**

|            | 现行 IRS 减免                                     | 8月3日 新声明                                    |
| ---------- | ------------------------------------------------- | ------------------------------------------------ |
| 北马里亚纳 | NMI-2026-01 · 超强台风 **Sinlaku** · 截止 11月2日 | DR-4931 · **另一场台风 Bavi** · 灾情自 7月4日 起 |
| 密西西比   | MS-2026-02 · 风暴龙卷 · 截止 11月2日              | DR-4930 · **热带风暴 Arthur** · 受灾县完全不同   |

同州同类灾害最容易被当成「同一件事的更新」,写成那样就是错报。

**德州 EM-3649**:出来 20 天仍无 IRS 公告,也无个人援助,107 家继续锁着 —— 判断不变。
