# 抖音适配打法(顶音)

抖音机制和小红书**反着来**,内容必须重做,不能照搬。

## 机制差异

| | 小红书 | 抖音 |
|---|---|---|
| 分发 | 搜索 + 收藏 + 推荐 | **算法推流**为主(完播/互动决定推多远,能滚雪球) |
| 用户目的 | 主动查干货、收藏 | 刷着玩、被动喂;要「爽 / 新奇 / 有用」 |
| 生死线 | 封面 + 标题(能被搜到) | **前 3 秒**(权重 40% = 封面点击率 + 2 秒跳出 + 3 秒留存) |
| 形式 | 图文轮播 | **视频优先**;图文能发但弱 |
| 结尾 | 引导收藏 | **超级指令**(点赞/评论/关注 CTA) |
| 考核 | — | 完播 35% + 收藏 25% + 铁粉互动 20% + 评论深度 15% + 转发 5% |

## 我们的内容怎么改

1. **钩子换成痛点/悬念/反转,不是陈述句**
   - 小红书:「加州 PTE 税延到 2030」(陈述,适合搜)
   - 抖音:「别以为加州 PTE 税到期了 —— 错」/「这个税会计师报错要赔钱」(悬念+痛点)
2. **前 3 秒公式 = 痛点提问 + 视觉冲击 + 悬念**(封面大字 + 第一句话就得抓住)
3. **形式优先竖版短视频**(15–40 秒):卡片当分镜 + 字幕/配音 + 热门 BGM;
   没条件先发**图文**(抖音也支持图文,但封面要比小红书更冲)。竖版 9:16 = `format:"dy"`。
4. **三段式结构**:结论(先给答案)→ 为什么(1 个案例/数字)→ 怎么做;每 15 秒一个转折。
5. **结尾超级指令**:「做加州客户的评论区扣 1」「关注不迷路,每周更新税务变更」。
6. **话题**:#财税知识 #会计 #报税 #CPA #税务 + 具体(#加州 #PTE #销售税)。

## 关键:同一条 alert,三平台三种打法(别一稿三发)

| 平台 | 钩子 | 形式 | 目的 |
|---|---|---|---|
| 小红书 | 陈述 + 可搜关键词 | 图文轮播 | 被搜到 + 收藏 |
| LinkedIn | 搜索磁石首行 + 专业 | 横版图 + 长文 | 被搜到 + 专业信任 |
| 抖音 | 痛点/悬念/反转 | 竖版短视频/图文 | 完播 + 推流 + 互动 |

## 加州样板

**封面(9:16 竖版)**:`card-renderer/out/ca-pte-douyin-cover.png` —— 悬念钩子「别以为 PTE 税到期了」。

**配文**
```
加州 CPA 注意⚠️ 别以为 PTE 选择性税 2025 就到期了 —— SB 132 又续了 5 年到 2030!

2026 起还变了两点:
1️⃣ 6/15 预缴迟缴/少缴,不再直接取消当年选择资格(以前差一分都不行)
2️⃣ 但迟缴的,该股东抵免按未缴部分砍 12.5%

Form 3804 / 3893 / 3804-CR 已出 2026 新版。
做加州客户的评论区扣个 1;关注不迷路,每周更新税务变更。

#财税知识 #会计 #报税 #CPA #加州 #PTE #税务 #美国报税
```

**竖版短视频脚本(20–30 秒,卡片当分镜 + 字幕 + 热门 BGM)**
```
0–3s  钩子   封面「别以为 PTE 税到期了」
      字幕/配音:做加州客户的会计师,别以为 PTE 选择性税 2025 到期了 —— 错!
3–10s 反转   数据卡 2025 → 2030
      SB 132 又续了 5 年,能用到 2030 税年。
10–22s 干货  实务提示卡(要点)
      但 2026 起两点变了:6/15 预缴迟了不再取消资格,但抵免按未缴部分砍 12.5%,新版 3804 已出。
22–28s 指令  封面 / logo
      做加州客户的评论区扣 1,关注每周更新税务变更。
全程竖版字幕;BGM 用悬念/轻快热门音。
```

> 现有卡片(小红书那套)直接当抖音视频的分镜用,不用重画;差别在**钩子话术 + 竖版 + 配音/字幕 + 超级指令**。图文党可先只发上面这张竖版封面 + 配文。
